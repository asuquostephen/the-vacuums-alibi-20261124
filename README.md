# The Vacuum's Alibi — entry

Entry for the make.fun competition [The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/c/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7) (slug `u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7`).

`main.py` (Python 3, standard library only) writes one line — the excuse a robot vacuum gives for missing a spot — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), verifying before it writes that the text is 1–200 characters and not only white space, and that the file round-trips byte-for-byte.

Run it:

    MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
    cat /tmp/out/entry.txt
